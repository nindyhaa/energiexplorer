# ⚡ Petualangan Energi dan Listrik - Kelas 6 SD

Materi pembelajaran interaktif tentang **Energi dan Listrik** untuk siswa kelas 6 Sekolah Dasar.  
Dibuat dengan tampilan cerah, ada gambar ilustrasi, dan quiz interaktif.

Cocok untuk dipakai sebagai media belajar mandiri atau bisa di-host di **GitHub Pages**.

## Fitur

- Menu klik-klik seperti aplikasi
- Warna cerah dan ramah anak
- Ada ilustrasi di setiap bagian materi
- Quiz interaktif dengan skor
- Responsif (bisa dibuka di HP)

## Isi Materi

1. Apa itu Energi dan Listrik
2. Berbagai Bentuk Energi
3. Perubahan Energi
4. Rangkaian Listrik Sederhana
5. Magnet dan Pemanfaatannya
6. Yuk Mengenal Lebih Jauh (sumber energi + tips hemat energi)
7. Game & Quiz
8. Kesimpulan

## Cara Deploy ke GitHub Pages

1. Upload semua isi folder ini ke repository GitHub kamu.
2. Buka **Settings** → **Pages**.
3. Pada **Source**, pilih branch `main` dan folder `/ (root)`.
4. Save, tunggu beberapa menit sampai link GitHub Pages muncul.
